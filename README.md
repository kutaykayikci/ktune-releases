# KTUNE · indir

**Windows için ücretsiz, reklamsız bakım aracı.** Açılışta habersiz başlayanları susturur, RAM'i kimin yediğini gösterir, gereksiz Windows uygulamalarını kaldırır, reklamı ve Copilot'u kapatır.

### ⬇️ [KTUNE'u indir (Windows 10 / 11, 64 bit)](https://github.com/kutaykayikci/ktune-releases/releases/latest)

Bu sayfadaki **Assets** altından `KTUNE-Setup.exe` dosyasını indirip çalıştırman yeterli. Hiçbir şey klonlamana ya da kurmana gerek yok.

> **"Windows bilgisayarınızı korudu" uyarısı çıkarsa:** KTUNE henüz kod imzalama sertifikasıyla imzalı değil. **Ek bilgi → Yine de çalıştır** demen yeterli.
